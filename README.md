🔸 فكرة عمل الكود:
استيراد المكتبات
مثل:
pandas لمعالجة البيانات
sklearn لبناء نموذج التعلم الآلي
تحميل البيانات
يتم قراءة مجموعة بيانات تحتوي على نصوص مع التصنيفات الخاصة بها.
معالجة النصوص (Text Preprocessing)
تنظيف النص من الرموز
تحويل النصوص إلى صيغة رقمية باستخدام:
CountVectorizer أو TF-IDF
تقسيم البيانات
تقسيم البيانات إلى:
بيانات تدريب (Training)
بيانات اختبار (Testing)
بناء النموذج
استخدام خوارزمية تصنيف مثل:
Naive Bayes
Logistic Regression
Support Vector Machine (SVM)
تدريب النموذج
تدريب النموذج على بيانات التدريب.
تقييم النموذج
حساب الدقة (Accuracy)
عرض تقرير التصنيف (Classification Report)
🔸 نتيجة المشروع:
النموذج يستطيع التنبؤ بتصنيف النصوص الجديدة بدقة جيدة.
يمكن تطويره ليشمل بيانات أكبر أو نماذج أعمق.
